# Drone Footage of Bee Nests

## 1. Short description

This registered item describes ground-level rasterized drone imaging of the Horizon Europe project **ProPollSoil - Understanding and managing soil health impacts to protect soil-dependent pollinators.**

Within ProPollSoil, we aim to develop and test new monitoring methods of ground-nesting pollinators. This dataset includes high-resolution images of nesting sites which are used to train deep learning models to detect nest entrances.
